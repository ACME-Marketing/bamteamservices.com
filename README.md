# bamteamservices.com

Holding-company site for BAM Team Services LLC (est. 2018, Florida). Astro + Tailwind 4, static, one page.

- `npm install && npm run dev`, then open http://localhost:4321
- Content and facts: `src/site.ts` (patents, timeline, contact). Page: `src/pages/index.astro`.
- Logo files and colours: `brand/` (see its README).
- Deploy: `deploy/deploy.sh` (Hostinger shared hosting). The live domain still serves the 2020 WordPress site; back it up before the first deploy.
